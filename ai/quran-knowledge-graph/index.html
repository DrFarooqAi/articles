About this tool

How the Graph is Built

📥
Data Pipeline

Quran text (Saheeh International) is fetched from the Quran.com API and structured into 114 Markdown files — one per surah — with metadata headers (revelation place, verse count) for richer context.

🧠
LLM Extraction

Graphify uses Claude to read each surah and extract semantic concepts — names, themes, commandments, narratives, places — then links them across the full corpus via co-occurrence and semantic similarity.

🕸️
Knowledge Graph

Nodes are surahs and concepts. Edges are connections. Community detection surfaces thematic clusters: Meccan vs Medinan revelation, prophetic stories, legal injunctions, eschatological themes.

🔍
Explore Freely

The interactive graph lets you click any node to see its connections, search by concept, zoom into clusters, and discover unexpected bridges between distant surahs.
